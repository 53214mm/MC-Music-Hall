# 水晶教堂 · 重构方案（待审核，尚未施工）

配套阅读：`design/诊断报告.md`（现有建筑的逐方块实测与批判）。
**本文件只提出方案，未改动任何建筑代码或产物。**

---

## 一、先把最硬的那个约束摆出来

现状：总宽 101 / 总长 136 / 总高 114，即 **高:宽 = 1.13**，体型是个矮胖的方块。

想要高:宽 ≥ 2.0，只有三种办法：

| 路径 | 做法 | 代价 |
|---|---|---|
| **A. 收窄** | 把总宽从 101 压到 57 左右 | 机房已占 43 格 + 两侧 7 格侧廊 = 57。**外宽压不下去**，只能压掉耳堂、缩短前部 |
| **B. 拔高** | 总高从 114 提到 115+ | 檐口高度 = 机房层数 × 12。**现有机房 6 层把檐口锁在 Y=91**，要檐口更高就得加楼层 |
| **C. 改轮廓** | 不动尺寸，只让平顶消失 | 只能改善"天际线读得出来"，**无法改变体型比例** |

**结论：C 是必做的，但只做 C 修不好比例。** A 和 B 里必须至少选一个。

### 需要你拍板的一个问题

**机房要不要从 6 层加到 8 层？**

- **维持 6 层**（檐口 Y=91，总宽 57）：高:宽 最好做到 1.55 左右。靠"屋顶可见 + 双塔高耸 + 平顶消失"把它做到**读起来是高耸的**，但体型的绝对比例仍偏矮胖。
- **扩到 8 层**（檐口 Y=115，总宽 57）：高:宽 可到 2.0，**真正进入哥特比例**。代价：多出 2 层机房，第 12、13 号模块需要新乐谱，红石时序、连接电路、材料表、施工图全部重做。

下面的方案按**维持 6 层**写（改动最小、风险最低），凡涉及 8 层的地方单独标注。

## 二、总体设计方向

**保留**：十字形平面、中央塔楼的主题、固定的听音点与音乐顺序、全部机房与红石时序。
**重做**：体型比例、天际线、屋顶系统、立面进深体系、材质体系、室内结构。

一句话方向：**把"一个 57×76×91 的白盒子顶上放穹顶和尖塔"改成"一座有明确檐口、可见坡屋顶、双塔门楼、和内部柱廊的哥特教堂"。**

## 三、整体体块关系

保留五个**有明确建筑意义**的体块，每个都必须能从轮廓上分辨出来：

| 体块 | 角色 | 在轮廓上的表现 |
|---|---|---|
| ① 核心体块（机房所在的十字交叉部） | 最高最宽的体量 | 檐口 Y≈92，有脊坡屋顶到 Y≈105 |
| ② 中央塔楼 / 尖塔 | 屋顶之上的垂直焦点 | 从屋脊长出，尖顶到 **Y≈140** |
| ③ 中殿（长向主体） | 纵深轴线 | 屋脊 Y≈58，明显低于核心 |
| ④ 双塔门楼（南端） | 前部标志 | 塔身到 Y≈80，尖塔到 **Y≈130** |
| ⑤ 侧廊 / 后殿 | 附属体量 | 单坡顶 Y≈30 上下，最低一层轮廓 |

**关键比例关系**（先定数字，再摆方块）：

- 核心檐口 92 ÷ 核心外宽 57 = **1.61**（现状 91÷57=1.60，靠屋顶和尖塔补足观感）
- 中殿屋脊 58 − 侧廊顶 30 = **28 格**落差，保证侧视有第二层轮廓
- 双塔尖顶 130 ÷ 塔宽 18 = **7.2**；塔身 62 ÷ 18 = **3.4**（哥特钟楼常见 3~3.5）
- 中央尖顶 140 ÷ 核心檐口 92 = **1.52**，让交叉部稳稳压过双塔

**禁止**：任何只有"高矮不同"而没有功能差异的两个相邻盒子。

## 四、平面布局

```
                 Z 轴（南 → 北）
  南端(-40) ──────────────────────────────→ 北端(+95)

  ┌──── 双塔门楼 ────┐  塔宽 18×18，外角与主体外角对齐
  │ 塔 │            │ 塔 │
  ├────┴── 中殿 ────┴────┤   净宽 28，长 44
  │  侧廊 │  中殿  │ 侧廊 │   侧廊净宽 ≥5（现状只有 1 格，必须改）
  ├──────── 十字交叉部 ────────┤
  │ 侧 │   核心机房 43×76   │ 侧 │   核心外宽 57
  │ 廊 │  廊道 Z=0..7      │ 廊 │
  ├────────┬────────┬────────┤
  │   后殿（多边形）      │   5 边，深 12
  └────────┴────────┴────────┘
```

**平面规则**

1. 侧廊净宽 **≥5 格**才成立；1 格宽的缝隙既走不进人也不成空间，属于"四不像"，本次一并修掉。
2. 侧廊外侧墙与主体外角**齐平**，靠内侧柱列产生凹凸——不要让侧廊外凸成另一个盒子。
3. 扶壁**间距 = 开间宽度**（中殿取 6 格），让结构节奏与视觉节奏是同一个数。
4. 耳堂进深从 ±21 收到 ±8，把总宽从 101 压到 **57**。
5. 前部总长从 103 收到 66（门楼 18 + 中殿 44 + 前廊 4），总长从 136 压到 **112~118**。

## 五、主体尺寸建议

| 部位 | 现状 | 建议 | 理由 |
|---|---|---|---|
| 核心外宽 | 57 | **57（锁死）** | 机房 43 + 两侧检修/布线 7×2 = 57，不可压 |
| 核心檐口高 | 91 | **92** | = 6 层 ×12 + 墙裙 8；结构不动，只改檐口做法 |
| 核心屋顶脊高 | 91（平顶） | **105** | 40° 坡，57 格跨 → 升 13~14 格 |
| 总宽 | 101 | **57** | 靠收耳堂达成 |
| 总长 | 136 | **112~118** | 靠收前部达成 |
| 中殿净宽 | 21 | **28** | 28 是"不空、不窄"的中殿净宽下限 |
| 中殿净高 | 56 | **44** | 56 太空旷且显压迫；44 配 28 宽 = 1.57 的经典剖面比 |
| 钟塔截面 | 13×17 | **18×18** | 塔身 62 高 ÷ 18 = 3.4，落在 3~3.5 区间 |
| 总高（含尖） | 114 | **140** | 140 ÷ 57 = 2.46；即使按可见主体算也有 1.85 |

## 六、塔楼尺寸与位置

**双塔（南端正面）**

- 截面 18×18，外角与中殿外角对齐，塔身从基座 Y=4 到 Y=66（**62 格**，比值 3.4）。
- 分三段：勒脚 4~10（外凸 1 格）、塔身 10~66（四角附扶壁，每 12 格一道束带层）、钟室 66~80（四面百叶窗 + 角部小尖塔）。
- 尖塔 80~128（**48 格**，八角形，用楼梯块收分），尖顶到 **Y=130**。
- **受控不对称**：右侧塔尖做到 130，左侧做到 122，顶部型制不同。哥特建筑罕见完全等高的双塔，1~2 格的差异就能让立面"活"起来。

**中央塔楼（交叉部上方）**

- 现状是直上直下的方筒（Y=87..98，1 格壁）。改为：**叠涩出挑的鼓座**（每 2 格外挑 1 格）+ 竖向肋 + 拱窗，从屋脊 Y=105 长到 Y=118。
- 尖塔 118~138，尖顶 **Y=140**。塔尖收头用 **y=139 的 2×2、y=140 的 1×1**——即 **0.25 / 0.5 / 1 方格**这种非整数收分，比直上直下的 1 格柱好看得多。

## 七、屋顶结构（本次改动的最大收益点）

现状：屋顶是 **1 格厚的薄板**，而且被砌到 91 的外墙完全挡住，侧视是一条直线。

| 屋顶 | 做法 |
|---|---|
| 核心主屋顶 | 双坡有脊，**2 格厚**，脊高 105；两侧山墙做实心带尖拱盲窗 |
| 中殿屋顶 | 双坡有脊，脊高 58，坡度约 40°；脊线用深色压顶 |
| 侧廊屋顶 | **单坡**（lean-to），内高外低，顶面比中殿高侧窗底低 2 格 |
| 后殿屋顶 | 多边形攒尖，与中殿屋脊在同一高度层次 |
| 老虎窗 | 中殿屋面每 12 格一个，只做 3 格宽的小老虎窗，用来打破大屋面 |
| 檐口 | 所有屋顶必须**外挑 1~2 格**形成檐口阴影线，这是"有厚度"的关键 |

**硬规则：外墙顶部必须低于屋脊，且屋面从侧面可见。** 现状的 91 格高墙把屋顶全挡住了，这是轮廓变成平顶盒子的直接原因。

## 八、入口设计

现状：Z=87 墙上的一个尖拱凹口，平墙、无门廊、远看读不出来。

- **外凸门廊**：从 Z=87 凸出到 Z=93，宽 20、深 6、高 24。
- **透视门洞（orders）**：门洞做 **3 层退进**，每层退 1 格并缩小 1 格，形成阴影层次。这是哥特入口的灵魂，比任何装饰都有效。
- **山花**：门廊上方三角形山花，比门廊宽 2 格，坡度与中殿屋顶一致（视觉上"屋顶顺下来"）。
- **台阶**：3 级台阶从地面抬到门廊地面，逐级收窄。
- **玫瑰窗**：位置保留（中殿正立面 Y=39 附近），但必须**退雕成凹龛**（内凹 2 格）+ 做放射状窗棂（tracery），不能是贴在平墙上的圆盘。

## 九、立面设计规则

1. **墙面永远不做 1 格厚**：墙体 **2~3 格厚**，外皮、填充、内皮分工。
2. **竖向三分**：勒脚（外凸 1 格）/ 墙身 / 檐口（外挑 1~2 格）。三段各用不同材料。
3. **横向分层**：中殿立面自下而上 = 拱廊层 / 高侧窗层 / 拱顶区。现状是一整片 56 格高的平墙，必须切开。
4. **至少 3 个进深面**：扶壁外凸 1~2 格 → 墙面 → 窗洞内凹 1~3 格。任何相邻两个面的落差不要只有"换色"。
5. **节奏**：扶壁间距 6 格，束带层每 12 格，窗与窗之间至少留 4 格实墙。
6. **细节密度随高度递减**：人眼高度（Y=0..12）最密，Y=12..40 中等，檐口以上只保留大关系。现状是均匀铺满，导致远看是一团、近看也没重点。

## 十、窗户与彩窗规则

- **窗洞必须先有洞，再有玻璃**：先退进 2 格形成窗龛，玻璃装在退进面，外侧留 1 格深阴影边。
- **尖拱窗**用楼梯块做出真正的尖拱轮廓，不要用方块拼成"尖"。
- **尺寸**：中殿高侧窗 3 宽 × 10 高；侧廊窗 3 宽 × 6 高；核心体块侧窗 4 宽 × 12 高。**窗宽不要超过 5 格**，超过就变成玻璃幕墙。
- **高侧窗成组**：每开间一组 2~3 扇，中间用石柱分隔，组间实墙 ≥4 格。
- **彩窗配色**：淡蓝玻璃为主（与音乐主题一致），紫色只做**窗棂与玫瑰窗放射线**，面积占比压到 5% 以内。现状紫色 0.8% 是对的，但用法是斜条纹，应改为**结构性的线**。
- **神圣感来自对比**：室内暗、窗洞亮。因此**不要把海晶灯做成外墙灯带**（现状做法），灯全部移进室内。

## 十一、材质 palette

现状问题：`smooth_quartz`(#e1e6e5) 占 33.7% 与 `white_concrete`(#e9eff1) 占 15.8% 明度几乎一样，两者大面积并用等于单色；`dark_prismarine` 以 2 格宽长条铺在屋面上，成为全局最抢眼却最无结构意义的元素。

**改成四级体系，每种材料只出现在一种结构角色上：**

| 级别 | 角色 | 建议材料 | 面积占比 |
|---|---|---|---|
| **主材** | 大面积墙体 | `smooth_quartz`（白）为主，`white_concrete` 只做主体填充 | 45% |
| **次材** | 扶壁、柱、勒脚、塔身分格 | `polished_andesite` / `smooth_stone`（灰一档） | 30% |
| **勾边** | 檐口、线脚、窗框、束带层 | `white_concrete` 或 `calcite`（亮且窄） | 10% |
| **强调** | 屋面、屋脊、塔尖、门洞内壁 | `dark_prismarine`（最深） | 10% |
| **玻璃** | 窗 | `light_blue_stained_glass` 主 + `purple_stained_glass` 仅窗棂 | 5% |

**规则**

- 明度必须拉开档：深 / 中 / 亮三档要一眼可辨。`smooth_quartz` 与 `white_concrete` 不得直接相邻做同一面墙。
- 强调色（暗海晶石）**只出现在屋面和塔尖**，不得作为水平长条贴在墙面上。
- 旧化不是"随机撒深色方块"，而是**沿结构线渐变**：勒脚深、越往上越浅；檐口下沿加深一道。
- 紫水晶块在现有外壳里一块都没有（`make_church` 把核心 Y>68 整段裁掉了），材质表里也不该出现。

## 十二、室内空间规划

现状：核心是 57×76×69 的真空，1 格厚壳，无柱无拱无夹层；中殿 21×56，墙面全平无柱列。这就是"外面大教堂、里面空盒子"。

| 空间 | 做法 |
|---|---|
| **侧廊（核心两侧）** | 修复现有的 2 格缝为**净宽 5 格真侧廊**：内侧开尖拱柱廊朝向机房，外侧开窗。玩家走侧廊、透过柱廊看机械——既是教堂侧廊，也解决了"机房只能站在广场上看"的问题 |
| **列柱** | 柱列间距 = 开间 6 格；柱础外凸、柱身 1×1、柱头外挑，总高 8~10 格 |
| **连拱** | 柱间用楼梯块做圆拱/尖拱，拱顶标高统一 |
| **拱顶** | 侧廊上方做石肋拱顶（2 格厚），**让屋顶从室内看仍然有结构**；机房区上方保留平顶但加肋梁 |
| **二层回廊** | 侧廊上方 3 格深处做夹层，靠柱廊一侧开小拱窗 |
| **中殿** | 加拱廊层 + 高侧窗层；两侧各 6 根柱；室内墙由 1 格加到 3 格 |
| **祭坛** | 后殿中央抬高 2 级台阶，背墙做尖拱盲窗组 |
| **楼梯** | 现有东侧梯井（X=47）保留，但包进侧廊内，不要裸露在立面上 |
| **采光** | 海晶灯移入室内：高侧窗窗台下一排、柱廊拱肩处一排、拱顶肋交点少量 |

**关键原则：外壳上的每一道扶壁，室内都要有对应的柱子。** 内外结构必须一一对应。

## 十三、主要视觉轴线

| 轴线 | 内容 |
|---|---|
| **主纵轴（Z，南→北）** | 台阶 → 门廊 → 透视门洞 → 中殿（44 格纵深，柱列夹持）→ 十字交叉（空间最高点）→ 后殿祭坛。这条轴线必须**通视无遮挡** |
| **主竖轴（Y）** | 门廊山花 → 中殿屋脊 → 核心屋脊 → 中央塔楼 → 尖顶。天际线自上而下读得出来 |
| **横轴（X，十字交叉）** | 两侧侧廊对称展开，柱廊 + 高侧窗形成被"夹持"的空间感 |
| **视觉重心** | 放在**十字交叉部**（核心体块 + 中央塔楼），而不是放在前部钟楼。现状的重心落在两座孤立小塔上，导致主体读起来是"背景板" |

## 十四、施工 / 重构顺序（每一阶段结束都要停下来看整体）

> 阶段之间**必须**留检查点：先看剪影（远景），再看近景细节。剪影不成立就不进下一阶段。

| 阶段 | 内容 | 完成判据 |
|---|---|---|
| **0. 保护** | 先把机房、红石、听音点、连接线路逐个标记为不可动区域并写进断言 | 现有 6 项测试全过，且新增"机房包围盒不得被修改"断言 |
| **1. 总体体块** | 收耳堂、收前部、定檐口与屋脊标高；只做体积，不加任何装饰 | 侧视/正视剪影里能看到 **≥4 个高度层次**，且不存在任何平顶长条 |
| **2. 主轮廓** | 核心坡屋顶 + 中殿坡屋顶 + 侧廊单坡顶；让外墙顶低于屋脊 | 侧立面不再是一条直线 |
| **3. 主立面** | 竖向三分 + 横向分层 + 扶壁节奏；墙面加厚到 2~3 格 | 任意一条水平剖线上材料/进深变化 ≥6 次（现状约 1 次） |
| **4. 屋顶细化** | 檐口出挑、屋脊压顶、老虎窗、山墙盲窗 | 屋面从 45° 视角有明确明暗层次 |
| **5. 塔楼** | 双塔分三段重做 + 中央鼓座叠涩 + 尖塔收分；做受控不对称 | 塔身比值落在 3~3.5，尖塔高 = 塔宽 ×2.3 以上 |
| **6. 入口** | 外凸门廊 + 3 层透视门洞 + 山花 + 台阶 | 从 50 格外仍能认出"这是入口" |
| **7. 窗户与彩窗** | 全部窗洞退进、尖拱轮廓、成组排列、玫瑰窗凹龛 | 窗组节奏与扶壁节奏对齐 |
| **8. 材质** | 按四级体系整体换色，去掉屋面长条与同明度相邻 | 灰度截图中结构层次仍清晰可辨（这条是判据，不看彩色） |
| **9. 细节** | 细节密度按高度递减；线脚、齿状挑檐、滴水嘴、铁艺 | 远看轮廓不变、近看有内容 |
| **10. 室内** | 柱列、连拱、拱顶、二层回廊、祭坛、采光 | 室内每一根柱子在外面都能找到对应的扶壁 |
| **11. 复测** | 全部 6 项核验重跑 + 机房零碰撞 + 听音点音量 | `python tools/verify_all.py` 全绿 |
