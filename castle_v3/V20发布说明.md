# 余响堡 V20 / Echo Castle V20

## 中文

这是余响堡当前完整施工资料的打包发布，目标版本为 **Minecraft Java 26.3-snapshot-9**。它不是已完成游戏内验收的存档。

### 下载与使用

下载附件 **`Echo-Castle-V20-Full-Build-Pack.zip`**，完整解压后打开 `release_v20/余响堡_V20施工总册.html`。GitHub下载附件使用英文名，压缩包内容与仓库内中文命名的ZIP完全相同。不需要Python，也不需要联网。GitHub自动提供的“Source code”是整个开发仓库，不是给手建玩家准备的精简施工包。

### 本版内容

- 整合V19主墙与V20侧墙：8根深扶垛、3组带托臂与雨檐的凸窗，新增2盏灯。
- 五项总册目录、六阶段施工顺序、16×16逐格工作台、中文摆法和全堡定位小图。
- 每页完成标记、撤销、按版本和原点隔离的进度，以及朋友之间的手动导出/合并。
- 完整模型、成品材料表、四张配图和324个NBT；原11个音乐模块、10条连接、53条路线和3处捷径保持。
- 中文 `README.md` 与英文 `README.en.md`，相互提供语言切换链接；施工总册界面仍为中文。

### 验证与注意事项

528,573非空气格，528,572件成品物品、88种，543个建筑光源、2,307个音符盒。相关83项Python测试以及脚本/数据检查通过；324个NBT已完整回读，与模型一致。

## English

This release packages the current complete **Echo Castle V20 building materials** for **Minecraft Java 26.3-snapshot-9**. It is not an in-game-validated world save.

### Download and use

Download **`Echo-Castle-V20-Full-Build-Pack.zip`**, extract it fully, and open `release_v20/余响堡_V20施工总册.html`. The ASCII-named download is byte-for-byte identical to the Chinese-named ZIP in the repository. Python and an internet connection are not required. GitHub's automatic “Source code” archives contain the whole development repository, not the smaller ready-to-use building package.

### Included

- Integrated V19 main-wall design and V20 side-wall improvements: eight deep buttresses, three projecting window groups with brackets and canopies, and two additional lights.
- A five-section manual, six construction phases, a 16×16 workbench, Chinese placement instructions, and a castle-wide location map.
- Undoable page-completion records, version/origin-bound progress, and manual export/merge for teammates.
- Complete model, finished-item quantities, four images, and 324 NBT tiles. All 11 music modules, 10 connections, 53 routes, and three shortcuts are retained.
- Chinese and English README files with language links. The interactive manual itself remains in Chinese.

### Verification and limitations

The complete build contains 528,573 non-air cells, 528,572 finished items across 88 types, 543 architectural lights, and 2,307 note blocks. The 83 relevant Python tests and script/data checks passed. All 324 NBT tiles were read back and matched against the model.

**Real-browser and Minecraft in-game acceptance testing remains outstanding.** Images are offline block-model renders. The NBT files contain 8,050,137 air cells and cover a 189×170×267 area. Use only a backed-up, separate, empty Creative test world; do not paste over a friend's server. Block updates, routes, mechanisms and save/reload behavior, nighttime lighting, and complete-song playback still require testing.
