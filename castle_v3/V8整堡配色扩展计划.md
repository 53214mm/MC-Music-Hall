# V8：扩展剩余灰墙的统一配色

用户认可V7有进步，要求剩余大部分灰色建筑也改变颜色且整体协调。本轮是第3步中的配色扩展，不把尚未完成的立面几何精修、照明协调或施工验收标成完成。

- 暖褐泥砖作为大面积墙身基调；门楼、西翼和上部塔廊的砖红与唱诗堂呼应。泥坯用于主堡Y=35…44的连续横带，避免全堡均匀散点；这一层只换材料，不把平墙变成凹槽。
- 现有暖砂岩窗框保持，新旧灰色切石装饰采用相同的浅色材料；生活翼保留木构和方解石填墙。
- 深板岩屋顶、铜绿小窗帽、水晶核心保持。灰色岩体、低处基座和受保护路面保留，形成深色下部与暖色上部。
- 只对现有建筑中水平邻格露空的灰色墙面进行同形状换材；不增加/删除坐标，不改变方块状态、窗洞、12处V7构件的非灰色成员或原音乐。

实施：独立读取integration_v7/castle_v7.json → 按建筑和高度确定材料 → 保存palette_v8完整模型与差异/材料表 → 相同原版模型纹理绘制南东/西南远景和墙面近景 → 检查形状、路线、音乐、灯具与源文件摘要。

验证：严格测试换材几何等价及保护规则；35条路线复核，原版状态解析，JSON回读，图片人工检查与HTML静态检查。不进行被阻止的本地浏览器自动访问，不改存档，无新NBT。

## 本轮结果（2026-09-13）

配色扩展已生成到 `palette_v8`。原位换材83,733格；完整模型518,511格，全部坐标和属性保持。25项相关测试通过，138种建筑/岩体状态解析通过；完整差异回读、14个源文件摘要、4张PNG和HTML静态检查通过。两组远景及两组近景均已人工查看。详见 `验证与进度.md` 的V8记录。

这只完成当前追加的整堡配色扩展；第3步剩余几何精修、第4步照明协调和第5步施工验收还未完成。
