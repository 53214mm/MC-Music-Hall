# V6 材质与照明

目标：回应“方块单一、几乎没有照明”。沿用V5几何，改变可见表皮、补齐实际灯具与分区照明；不重新设计体量，也不写入游戏存档。

1. 表皮：凝灰岩砖/磨制凝灰岩做厚重基座，石砖与安山岩成片过渡；窗框、转角保留浅色切石。深板岩瓦与深板岩砖区分屋面；修补区使用有边界的木构和灰泥，不作全墙随机噪点。
2. 灯光：入口与路边灯座，塔内/回廊悬灯，立面小灯龛，唱诗堂吊灯。原音乐核心冷色灯保留；不使用火、岩浆、通电红石灯或隐形光源。
3. 交付：V5/V6实方块对照、灯位图、逐层状态、材料和灯具清单；V6另存，不覆盖V5或原NBT。
4. 检验：音乐及保护体积不变、旧方块几何不删、路线支撑/净空、灯具支撑、目标版本ID。灯距/光照图只是静态辅助，不能当成游戏防刷怪验收。

风险：普通方块替换可改变红石导电与音色，故整片音乐保护区及音乐周围一格全部冻结；新灯不得占据通路前三格净空。普通墙面只做同几何换材，原有楼梯/台阶方向保持。

官方灯具资料：[灯笼](https://www.minecraft.net/en-us/article/taking-inventory--lantern)、[蛙明灯](https://www.minecraft.net/de-de/article/block-month--froglight)、[海晶灯](https://www.minecraft.net/en-us/article/block-week-sea-lantern)。普通灯笼、蛙明灯、海晶灯均为15级发光；静态预览不等于Minecraft光照引擎。
