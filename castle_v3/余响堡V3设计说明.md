# 余响堡 · 最后的合唱

V3空间设计，2026-09-12。用户已确认：优先厚重城堡感，浅灰石材和深色屋顶，水晶只保留在音乐核心。

本轮完成了资料研究、体量方案、空间关系与叙事策划。**这份文件和空间总图不是已经展开完毕的逐格施工图。** 方案将整套音乐机与连接整体下沉32格，相对位置和时序不变；原NBT未修改。上一版施工文件保留，不能把旧材料数量用于本方案。

## 1. 不再以六层机房决定外墙长相

上一版的问题不只是装饰稀少：六层等高重复窗、规整基座、对称门楼和统一屋面，把每个功能空间都直接表现成方盒。局部凹窗虽变丰富，远景仍缺少主次。

V3将内外层次分开。音乐机保留在内堡，外部不再每12格横向画一圈檐线，而由厚重扶垛、狭长窗组、偏心石冠和附属塔遮挡其规则网格。城堡外围以城墙、露天庭院和少数侧翼围合，空隙与高差属于设计本体，不用房间填满。

### 轮廓层级

| 层级 | 本项目方案 | 作用 |
|---|---|---|
| 地形 | 不规则岩岬，底部约设计Y=-48；入口在较低坡面，路径折入门道 | 野外先见主峰，接近后被岩壁遮住，再重新露出 |
| 外城 | 顺地形折转的厚城墙、两座不等高门塔、短桥 | 建立人身尺度与防御尺度的反差，不抢内堡天际线 |
| 侧翼 | 低营房、厨房、较高藏谱室、偏置礼拜堂 | 功能与轮廓有对应，不是任意大小的盒子堆放 |
| 主体 | 部分埋入岩体的内堡、偏心冠楼；最高石冠约Y=118，水晶采光口降至内堡屋面 | 用厚重石塔统领轮廓，水晶不再充当天际线尖顶 |
| 次高点 | 西北独塔，比主峰低；东侧阶塔与西残塔再降低 | 形成可辨识的侧面，不追求四角完全对称 |

这不是增加一圈城墙就完事。门楼与内堡之间留出前庭、回廊与侧翼，远处看到的上层结构必须在游线中能够解释。场地尚未实测，岩岬只是可调整地形方案，不要求把巨大包围盒全部填实。

## 2. 游线必须有明确的体验次序

主线：断碑坡道 → 守门人小室 → 余烬前庭 → 旧营房收容所 → 厨房 → 空井回廊 → 服务阶梯 → 藏谱室 → 回望悬廊 → 空席礼拜堂 → 日光庭院 → 东侧阶塔 → 音乐核心。

其中“低窄、开阔、低窄、通高、露天、沉静终点”交替。第一次到达音乐核心不走直线，但第二次到达应更方便。所有探索支路均可跳过；基础主线不能要求高风险跑酷。

### 三处空间重叠

1. **空井回廊**：地面环廊、上方悬桥、下方干蓄水池属于同一个位置。首次仰望桥；上桥后回望井；下层通过水痕与井壁认出旧空间。
2. **藏谱室**：先在下厅看见上廊与缺口，之后从侧梯到达上层，再打开折返梯。书桌、窗和曲谱柜作为上下层共同的定位点。
3. **音乐内堡**：先在庭院见高处微弱冷光，进入外围检修廊后见到局部机械，最后抵达既定听音平台。音符盒不是为了造景随意挪动；游线围绕设备净空布置。

### 环路和捷径

| 编号 | 初次游览 | 开启后 | 意义 |
|---|---|---|---|
| S1 | 前庭绕营房、厨房到空井，便门从前庭侧不可开 | 空井内侧开门返回前庭 | 在熟悉地点辨认自己完成了一圈 |
| S2 | 藏谱室下厅经侧边回转梯上楼 | 从上层放下折返梯，接回下厅 | 上下层成为可复用的同一空间 |
| S3 | 日光庭院经东翼长廊和阶塔到检修层 | 内侧打开维修者通道，缩短返回路线 | 给反复听歌和维护设备的人实用回路 |

关系图已验证：不使用捷径也能到达所有主线节点，三个捷径都能缩短各自端点之间的最短折线。**这不是Minecraft实际步数或净空验证**；竖向关系尚须展开成带休息台的楼梯。

蓄水池另有一条地下来回路，接回前庭，不把所有捷径都表现为同一种铁门。无名纪念龛与旧工坊是两个真正的短死路：分别给情绪停顿和维修线索，不再硬接另一条走廊。独塔观景位是探索奖励，而不是强制绕远点。

## 3. 一个故事，贯穿内饰而不依赖长告示牌

原创设定：这里曾是驻防城堡，战争后收容过撤离的人群。撤离发生后，大部分空间失去用途；某位维修者仍维持音乐机关，让一首为离去者演奏的曲子继续响起。

不直接复制《艾尔登法环》的角色、接肢剧情或物品摆放。以下是本项目独立设定，音乐为《Departures》。

| 房间 | 原本用途 | 如今看见的变化 | 具体物件关系 |
|---|---|---|---|
| 守门室 | 值勤与登记 | 人已离开，但最后一班记录未收走 | 桌椅保持朝向，门旁集中堆空箱，不能全屋随机撒箱子 |
| 营房 | 整齐军床 | 被改为临时收容空间 | 不等长床铺、拼接长桌、隔开的小照护角 |
| 厨房 | 集体供餐 | 炉台冷却，局部仍有人用 | 大灶停用，仅小工作台干净；碗与座位数量不对应 |
| 藏谱室 | 档案与抄写 | 普通书架破损，曲谱柜却被修过 | 旧柜配新木板；上层才能看到背面的重新编号 |
| 礼拜堂 | 集体仪式 | 席位空缺、有人留了一张谱 | 主座偏离轴线，窗边新石修补旧墙，少量暖灯照向空席 |
| 旧工坊 | 维修 | 无人工作的旧车间 | 损坏音管与备用零件形制对应核心，解释维护历史 |
| 蓄水池 | 供水 | 水位退去、另有梯子 | 连续水线、堵塞进水处、后来加的踏步组成因果关系 |
| 音乐核心 | 集会演奏 | 仍在工作 | 整洁维修廊、备用工具、空指挥位；冷色水晶只在这里集中出现 |
| 独塔 | 警戒 | 朝向来路的守望位置 | 只放一张椅子和一盏灯，用位置表达等待 |

“破旧”也须有规则：潮痕靠近水道，风化集中外角，落石出现在破口下方，修补木构通向仍有人维护的空间。花纹与破损不平均撒满墙面。地面、门窗和可行走边缘仍须好辨认。

## 4. 材料与近景尺度

配色方向，不是采购数量：

- 主体：石砖、安山岩、凝灰岩砖等低对比灰石。裂纹与苔痕只在原因明确的区域少量使用。
- 转角、檐口、门框：较浅的磨制石材，用进深先形成阴影，再考虑雕花。
- 屋面：深板岩系深灰屋顶；只保留少量高尖顶，多数外墙以厚城垛或石冠收口。
- 生活内饰：云杉木、深色木构、暖色灯笼。木构补强应有柱脚和横梁支承，不漂浮。
- 核心：局部淡蓝/紫色玻璃与水晶，黑暗中可识别，但不做全楼玻璃幕墙。

近景施工设计目标：主门道净宽5格左右；一般主路净宽3格、检修路至少2格；普通路线净高至少3格，楼梯有休息台和护栏。重要大厅在局部挑高，不是每一个房间都做巨大教堂。具体方块比例需一组样板实际行走后确定。

## 5. 与音乐机的硬约束

原11模块与连接整体平移(0,-32,0)，相对坐标和时序不变。外壳与新楼梯必须避让现有线路、音符盒顶面的空气与维护空间。关系图中平移后的保护区为设计范围 X=-7…49、Y=-34…45、Z=-36…37，是保守约束，不是可以随意填充的实心区域。冠楼与内堡在灰模中相交；未来施工模型必须合并空间并挖除保护区，不可把两个体量分别砌成实心。岩体也必须挖出入口、蓄水池和机房，当前灰模未做这些洞口。

听音平台随整机平移到设计坐标(21,-3,4)附近（地板高度），站立脚底约Y=-2；从东侧阶塔下降19格抵达。只有这一区域承担“完整听曲”的验收；外城和庭院不承诺听完整首。不会为了做更长城堡把音乐机水平拉散。设计Y尚非世界Y，选定世界原点后须整体换算并检查高度边界。

S1—S3首先是空间连接方案。门闩、折梯等需要各自的Minecraft样板与红石隔离验证，不能把图上的“开启捷径”复选框误认为已经实现了游戏机关。

## 6. 下一个施工版本的验收门槛

本轮随后已展开第一组西翼样板，见 `west_wing_sample/西翼回廊_逐格样板.html`。它包括8条静态检查路线、偏置抄谱间、门廊与圆窗，附独立材料表和NBT测试分块；尺寸和最新块数以样板报告为准。样板还没有在游戏内实走，不能因此把以下全堡验收标记成完成。

继续展开后，南门、南岩岬与西翼已合并为 `gate_west_combined/余响堡_门楼与西翼联建图.html`。本联建单元共有17条检查路线，原西翼26,989个实体状态逐个保留；门塔露台、东塔三段楼梯、跨门巡廊与前庭回路均已展开。总图相应更新了南侧入口位置和双门塔尺寸。联建测试必须使用新的一整套NBT，不能与旧西翼的含空气分块叠加导入。自动浏览器打开本地HTML被安全策略阻止，当前联建网页尚未完成浏览器视觉验收。

1. 从南侧坡道、西侧野外、东侧远景三处检查轮廓：必须认得同一主峰，不能变回一排等高楼房。
2. 先做“前庭—生活侧翼—空井—藏谱上下层—便门”这组空间样板，验证视线与第一次/第二次路线，再拓展全堡。
3. 所有主线按玩家体积逐格检查支撑、净高、转角、楼梯坡度；重新检查与音乐设备不相交。
4. 对照故事检查每个物件：服务用途、损伤原因、修补年代至少能解释一种。删除无意义堆砌。
5. 通过后才生成V3完整NBT、分块、准确材料数与逐层施工网页。现有 `music_hall` 仍是V2教堂版；V3文件独立保存在 `castle_v3`，V2另备份到 `design/church_v2_20260912`。
