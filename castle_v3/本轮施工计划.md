# V3 可行走样板计划

本轮围绕主堡西侧的空井回廊、下层蓄水池、上层悬廊与藏谱室制作实际方块样板。它是全堡的第一组施工单元，不是整堡已完成。

1. 保留总图与原音乐NBT；样板全在音乐保护区西侧，不触碰曲谱和电路。
2. 用真实方块展开三层重叠空间：地下Y=-12、回廊Y=0、悬廊/藏谱下厅Y=16、藏谱上廊Y=32。先通路，再门洞与柱廊，再内饰与屋顶。
3. 以样板生成结果为验收边界：路线中心至少三格净高；连续一步只平移一格或升降一格；升降连接必须有正确方向的楼梯。记录侧向净宽；缺支撑、障碍和反向台阶须被测试发现。该保守模型不模拟完整Minecraft碰撞盒。
4. 输出独立HTML（真实方块预览、剖切、逐层图、精确材料表）、NBT测试分块及偏移表，读回校验。未实现的捷径门闩不伪装成自动机关。
5. 同步总图中的机房整体下沉32格与坐标提示，保留研究依据。全堡精确材料和最终NBT待后续单元展开后计算。

风险：世界坐标尚未选择；样板NBT只适合空白创造测试区；输入不含空气的稀疏NBT不会自动挖空已有地形。原先总图只是拓扑，样板的楼梯、门洞可能使精确坐标微调，样板内部以逐格输出为准。
