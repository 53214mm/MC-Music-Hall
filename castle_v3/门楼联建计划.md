# 南门与西翼联建

目标：把南侧抵达段变为可走的真实方块模型，并与西翼前庭设计坐标(-38,0,74)衔接。沿用已确认的灰石堡垒、深屋面与水晶只留核心的方向，不修改音乐NBT。

方案取舍：采用两座不等高、不同屋冠的多边形门塔，门厅通过折转楼梯进入前庭；东塔楼梯可到上层巡廊，越过门厅后经西侧楼梯回到前庭，形成真正环路。岩岬做有裂隙的空心表层，桥跨裂隙，不把地基填成巨大实心方盒。

功能单元：

1. 岩岬、拱桥和坡道：验证连续踏步与五格路宽；区分地形材料与建筑材料。
2. 门厅、双塔和巡守回路：验证所有登楼楼梯三格宽/三格高，保护主门净空，给守门室、补给角和眺望位布置用途明确的物件。
3. 与西翼联建：坐标共用，原西翼实体状态优先保留，复查全部旧路线与新路线。只导出合并测试分块，避免两个含空气的分块组互相擦除。
4. 独立HTML、材料表、含空气NBT、偏移与验收说明。总图添加入口并同步门塔体量，不能继续用过时的概念坐标替代已展开的路线。

风险：未选世界原点；新联建图的最小角不同于旧西翼最小角。含空气NBT必须只在隔离创造区导入；当前不包含完整城堡、音乐核心，也未做游戏内行走和光照验收。
