# V7样板材料与搭建说明

仅对应3个独立试样，不是全堡采购清单。不含工具和脚手架。局部坐标以样板左后底角为0，Z增大朝正面。原堡、音乐机与灯光文件都未改。

## A · 暖石尖拱窗跨

共1496个非空气方块；包围范围X=0…18，Y=0…33，Z=0…11。显示范围包含留白，不代表每格都要填满。

1. **厚墙与基座**：先搭X=0…18、Y=0…2的凝灰岩砖基座；红砖墙在Z=2…3。窗口玻璃放在后侧Z=2，前面保留空隙。
2. **窗洞、窗套与细窗棂**：窗口X=5…13从Y=7起向上收尖。外圈暖砂岩；内侧云杉栅栏形成细窗棂，倒置楼梯做小窗头。栅栏、墙的连接由邻块决定，按逐层图搭。
3. **窗扇、窗台、托石**：外侧深橡木活板门手动打开为竖片；Y=6用上半台阶做薄窗台，Y=5的磨石是托件。不要把活板门位置填成整块。
4. **檐口与灯**：Y=27的倒楼梯之间留空，上方用上半台阶压边；灯笼挂在栅栏下方。小范围铜绿只用于上部窗帽。

## B · 变坡老虎窗与薄檐

共740个非空气方块；包围范围X=0…12，Y=0…20，Z=0…10。显示范围包含留白，不代表每格都要填满。

1. **窗芯**：先搭红砖窗芯，窗玻璃在Z=6，细窗棂和浅色窗框在Z=7。
2. **变坡屋面**：从两侧向中心，每格屋面高度依次为9、10、11、13、15、17、18；镜像搭另一侧。跨两格高度的位置需要完整砖块封住下方，不能只留悬空楼梯。
3. **薄屋檐**：前后山墙用倒置砂岩楼梯托住深灰瓦，最外侧Z=10用半台阶收薄；不要把倒楼梯之间的缺角填实。
4. **屋脊灯**：屋脊上加半台阶，前端栅栏向下吊一盏灯。铜绿留给A窗帽，B不再重复同色装饰。

## C · 外挑木窗与三格托架

共674个非空气方块；包围范围X=0…12，Y=0…18，Z=0…10。显示范围包含留白，不代表每格都要填满。

1. **下墙与木架**：凝灰岩砖打底，方解石填墙；主木柱竖向，Y=7、14横梁用横向原木，别让木纹方向都一样。
2. **三格托架**：每侧依次是贴墙倒楼梯、外移一格并升一格的倒楼梯、最外侧上半台阶；阶梯形下面是空气，不是三角实心墙。
3. **外挑窗体**：Y=8搭外挑平台，玻璃在Z=5、细栅栏在Z=6；活板门只做平台边沿与窗扇。
4. **铜帽和灯**：小窗顶用打蜡斑驳切制铜台阶，上下半格交替形成缓坡；檐下再加薄木台阶。灯笼挂在梁下，避开窗台操作面。

## 手建注意

- 木活板门可手动开合；open=true表示竖起的薄片，closed/false表示水平，half决定铰链高度。此处不使用需要供电才能维持打开的铁活板门。
- 楼梯的facing、half和转角、墙/栅栏连接状态需要在游戏中复核；自动更新可能改变外观。页面给的是设计状态，不保证游戏放置顺序完全相同。
- 样板灯具已有连接构件，但没有完成存档导入、游戏碰撞、光照或结构更新验收。不能把这组试样直接覆盖到音乐机附近。
- 原版模型和纹理直接从本机合法安装读取；仅输出建筑示意PNG，不打包或分发材质资源。绘图不含环境遮蔽、游戏光照、UV锁定和生物群系染色，动画材质取首帧。
- 全堡仍以V6作存档底稿；V7只是待确认的构件方向，不是成品总方案。
