# 余响堡 V3：全堡导入与验收说明

范围 **189×170×266 格**；城堡设计最小角 `(-90, -48, -84)`，最大角 `(98, 121, 181)`。
这是**全堡**逐格数据，已经包含此前交付的门楼与西翼全部实体，**不要再叠加导入旧联建分块**。

## 一、导入安全

本目录 324 个分块 NBT **明确包含空气，会覆盖整个 189×170×266 长方体**
（共 8,546,580 格）。只能导入**备份后的隔离创造测试区**。

- 不要覆盖已放置的音乐模块；本组合已完整包含平移后的音乐机（2307 个音符盒）。
- 不要与 `gate_west_combined`、`west_wing_sample` 的分块叠加。
- 没有修改任何游戏存档。

## 二、坐标换算

- 城堡设计坐标 = 本目录坐标 + `(90, 48, 84)`。
- 分块世界最小角 = O +manifest.offset（O 为本包最小角的世界位置）。
- **音乐机整体平移 (0,-32,0)**：原设计坐标 (x,y,z) 现在位于 (x,y-32,z)，状态与相对位置不变。
- 听音台重设在**机器顶面 y=34**（详见第六节）。

## 六、本轮据实记录的两处偏差

### 1. 听音台标高与设计说明不一致

设计说明写的是听音台在 (21,-3,4)。**实测：平移后机器占 Y=-32..34，该点落在机器体内**，
与设计说明自述的「先在庭院见高处微弱冷光，进入外围检修廊后见到局部机械」相矛盾。
本轮把听音台改设在**机器顶面 y=34**，并由 x=45 的独立上升梯登顶；机器本体一个方块都没有改动。
如需严格按 (-3) 标高，必须先给出一张机器内部检修通道的逐格图。

### 2. 四条新增游线在旧实体不变的前提下不成立

| 路线 | 原因 |
|---|---|
| 前庭—收容长屋—厨房—西阶 | 旧西翼 y=0 步道占满 x=-50..-66、z=34..75 的通道，新路线在任意 Y 层都与旧实体相交；需先确定是否允许在上层跨越或另开洞口。 |
| 回望悬桥—唱诗堂 | 起点 (-19,16,42) 及其附近格子被旧西翼实体占据，旧「藏谱下厅—回望悬桥」的终点并不落在空位上，接入点需要重定。 |
| 空土庭返回前庭的常开环路 | z=74 与 z=92/96 两段在 x=-11..-38 范围与旧屋体相交；实测 z=84、z=88 两条车道为空，可改走该处，但需把西翼终点一并移到同层（自 y=16 平台到 y=0 车道的下降段还缺一段合格楼梯）。 |
| 东侧长廊—上升梯口 / 上升梯—机器顶面 | 新增上升梯的净空与既有「东侧长廊」端点在同一格共面，反复相交；要接通必须先指定谁让出该格，属需要人工决策的接口问题。 |
| 藏谱上廊—北塔 | 旧「藏谱上廊环路」占满 x=-44..-22、z=-12..12 的 y=32 走廊，且档案塔在 y=32 整层实心、没有开口。要连通北塔必须先确认能否在塔身开洞。 |

这四条没有强行打通，也没有移动旧实体；它们不影响已通过的主线。
