# Departures 红石音乐机施工数据

## 固定参数

- 量化速度：10 红石刻/秒
- 模块：11 个，每个 16 小节；最后一模块保留到 MIDI 的 5:47.5
- 音符盒：2307
- 时间线中继器：1475（已按 4、3、2、1 刻压缩空拍，并包含模块交接尾段）
- 线路红石粉储备：3754
- 低于原版总音域并升高一八度的原始音：5
- 升八度后与既有音重合并合并的触发：4

## 音色垫块

- 泥土：1457
- 橡木木板：384
- 浮冰：466

## 文件用途

- `departures_full_10tps.nbs`：整首试听和总校验。
- `departures_module_01.nbs` 至 `departures_module_11.nbs`：分别在 OpenNBS 中导出结构。
- `departures_note_schedule.csv`：每个音符盒的时间、音高、垫块和右击次数。
- `departures_timing_modules.csv`：主时间线每一段中继器的档位。
- `departures_materials.json`：精确逻辑材料统计。

## 施工规则

1. 每模块从 `local_tick=0` 接收启动脉冲。
2. 按 timing CSV 依次放置中继器；`4-4-2` 表示连续放两个四档、一个二档中继器。
3. 每到一个事件点，从主线侧面引出该行所有音符盒；同一 global_tick 的音必须同时供电。
4. 音符盒下面按 schedule CSV 放对应垫块，然后从默认 F# 音高右击指定次数。
5. 每模块 handoff 行的最后一个中继器输出接下一模块启动端。
6. 音符盒顶部始终留空气；相邻事件分支用中继器或实体方块隔离，禁止红石粉串线。
